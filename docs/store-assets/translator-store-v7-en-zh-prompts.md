## Shared prompt constraints

Use a clean 16:10 layout with a webpage on the left and the extension UI on the right. Divide the left page into exactly two equal-height sections: Chinese original above and English translation below. Use only a small, simple gray image-placeholder icon by each section title. Keep both text sections readable and make the extension UI the main subject. All extension UI labels are English. Avoid API keys, error counts, fake failures, extra tabs, or watermarks. Display version v0.1.1.
